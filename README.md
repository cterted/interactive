# 🎯 目标分解科研工具

基于 ECharts 的交互式目标分解可视化工具，支持图结构和树结构的灵活切换，适用于科研项目管理、产品设计和需求分析。

## ✨ 核心功能

### 1. 📊 可视化展示
- **图结构模式**：展示节点之间的复杂关系和依赖
- **树结构模式**：层次化展示目标分解的上下级关系
- 支持缩放、平移、拖拽等交互操作

### 2. ✏️ 节点管理
- **添加节点**：支持 4 种节点类型（目标、任务、里程碑、资源）
- **编辑节点**：修改节点名称、类型、描述信息
- **删除节点**：移除节点及其相关连接
- **拖拽节点**：自由调整节点位置（图结构模式）

### 3. 🔗 连接管理
- **添加连接**：建立节点之间的关系（如：依赖、包含、跳转）
- **删除连接**：移除不需要的关系
- **关系标注**：为连接添加说明文字
- **方向指示**：箭头显示关系方向

### 4. 💾 数据持久化
- **保存数据**：导出为 JSON 格式文件
- **加载数据**：从 JSON 文件恢复项目结构
- **导出图片**：生成高清 PNG 图片用于演示

### 5. 🎨 美观界面
- 现代化渐变色设计
- 响应式布局，适配各种屏幕
- 流畅的动画效果
- 友好的提示信息

## 🚀 快速开始

### 使用方法

1. **打开工具**
   ```bash
   # 在浏览器中打开
   open goal-decomposition-tool.html
   ```
   或直接双击 `goal-decomposition-tool.html` 文件

2. **添加节点**
   - 点击 "➕ 添加节点" 按钮
   - 填写节点信息（名称、类型、描述）
   - 点击确认即可添加

3. **编辑节点**
   - 点击图中的节点进行选择
   - 点击 "✏️ 编辑节点" 按钮
   - 修改节点信息后确认

4. **删除节点**
   - 点击图中的节点进行选择
   - 点击 "🗑️ 删除节点" 按钮
   - 确认删除

5. **添加连接**
   - 点击 "🔗 添加连接" 按钮
   - 选择源节点和目标节点
   - 可选填写关系描述
   - 点击确认

6. **切换布局**
   - 点击 "🔄 切换布局" 按钮
   - 在图结构和树结构之间切换

7. **保存项目**
   - 点击 "💾 保存" 按钮
   - 自动下载 JSON 文件

8. **加载项目**
   - 点击 "📂 加载" 按钮
   - 选择之前保存的 JSON 文件

9. **导出图片**
   - 点击 "📸 导出图片" 按钮
   - 自动下载 PNG 图片

## 🎯 节点类型说明

| 类型 | 颜色 | 用途 |
|------|------|------|
| 目标 | 紫色 | 主要目标、核心目标 |
| 任务 | 蓝色 | 具体任务、子任务 |
| 里程碑 | 粉色 | 重要节点、检查点 |
| 资源 | 绿色 | 所需资源、工具、人员 |

## 🔧 技术特点

- **纯前端实现**：无需服务器，直接在浏览器中运行
- **零依赖**：仅需 ECharts CDN，无其他外部依赖
- **响应式设计**：自适应各种屏幕尺寸
- **数据格式标准**：使用 JSON 格式，易于集成和扩展
- **可扩展性**：可方便集成 AI API 实现智能建议

## 💡 使用技巧

1. **合理使用节点类型**：不同颜色帮助快速识别节点性质
2. **添加描述信息**：鼠标悬停可查看节点详细信息
3. **定期保存**：养成保存习惯，避免数据丢失
4. **图树切换**：
   - 图结构：适合展示复杂关系
   - 树结构：适合演示汇报
5. **拖拽调整**：在图结构模式下自由调整布局
